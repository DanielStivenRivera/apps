# DroidDeck · Privacy Policy

Privacy policy for **DroidDeck**, the Android app that turns your phone into a Bluetooth keyboard, mouse
and media remote. Published with GitHub Pages.

- Español: `https://<usuario>.github.io/droid-deck-privacy/#es`
- English: `https://<usuario>.github.io/droid-deck-privacy/#en`

The page picks the language from the browser and can be switched at the top. Adding `#es` or `#en`
to the URL forces a language, which is useful for store listings.

## Updating

Edit `index.html` (both the Spanish and English sections) and update the effective date in each.
